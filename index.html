Odczyt KCh z pomocą Copilot

ChemRisk nie przesyła pliku do Copilot automatycznie. Wykonaj kolejno poniższe czynności:

  1. W osobnej karcie otwórz Microsoft 365 Copilot.
  2. W Copilot dodaj jako załącznik tę samą kartę charakterystyki PDF.
  3. Poniżej kliknij Kopiuj prompt, a następnie wklej prompt do Copilot klawiszami Ctrl+V.
  4. Wyślij wiadomość i poczekaj na odpowiedź w formacie JSON.
  5. Skopiuj cały JSON z odpowiedzi Copilot.
  6. Wklej JSON w pole Wynik JSON z Copilot i kliknij Wczytaj dane do formularza.
  7. Sprawdź dane z oryginalną KCh. Każde pole możesz uzupełnić lub poprawić ręcznie.
